# Zadanie TB-1

## Część 2: Opis danych i wstępny diagram ERD

**Cel:** opisać dane przechowywane przez aplikację TaskBoard z demo, a następnie przedstawić ich wstępny model relacyjny.

### Do wykonania

- Skopiować `materialy/dane-szablon.md` do `docs/dane.md` i opisać użytkownika, tablicę oraz zadanie (co najmniej cztery informacje i przykładowe wartości dla każdego obiektu).
- Opisać powiązania między użytkownikami, tablicami i zadaniami w co najmniej trzech zdaniach oraz dodać przykład zadania w JSON.
- Na końcu `docs/dane.md` umieścić diagram ERD w Mermaid z tabelami, kolumnami, typami, kluczami głównymi (`PK`), obcymi (`FK`) i powiązaniami.
- Usunąć komentarze z pytaniami pomocniczymi z uzupełnionego szablonu.
- Przygotować branch `feature/tb-1-dane`, commit i pull request do `main`; workflow ma być zielony, a pull request scalony przez merge commit. Nie usuwać brancha.

### Kryteria ukończenia

- `docs/dane.md` zawiera opisy użytkownika, tablicy i zadania z przykładami.
- Powiązania są opisane w co najmniej trzech zdaniach i zawierają przykład JSON.
- Diagram ERD przedstawia co najmniej trzy tabele, ich klucze główne i obce oraz relacje.
- Pull request z brancha `feature/tb-1-dane` jest scalony do `main` przez merge commit; branch pozostaje na GitHubie.
