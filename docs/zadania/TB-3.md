# TB-3: Frontend, integracja i oddanie projektu

## Część 1 — frontend i integracja

- Trzy strony HTML: login, lista tablic i widok tablicy na Bootstrapie 5.3 i własnym CSS.
- Logowanie, rejestracja, komunikaty API i przekierowanie po sukcesie.
- Tablice: lista kart, nazwa, opis, właściciel, dodawanie i edycja w modalu, usuwanie z potwierdzeniem.
- Zadania: trzy kolumny, modal z danymi zadania, edycja, szczegóły, status i usuwanie z potwierdzeniem.
- Na widokach chronionych imię użytkownika, Wyloguj i wymaganie sesji.
- Branch feature/tb-3-frontend, zielony workflow, pull request i merge commit do main.

## Część 2 — rozbudowa, testy i oddanie

- Branch feature/tb-3-oddanie.
- Łączone filtry: priority, assigneeId, q (fragment tytułu), również w API.
- Walidacja wszystkich formularzy i komunikaty błędów API.
- Responsywność, dostępność Lighthouse co najmniej 90 i walidator W3C bez błędów.
- Co najmniej 10 przypadków w docs/testy.md, opis tras w docs/api.md.
- Końcowe README: baza, konta.sql, .env, npm install, npm start, konta testowe, zrzuty i czysty klon.
- Pull request z merge commit do main, potem tag v1.0.

Wyniki ręcznych testów zapisujemy tylko po ich rzeczywistym wykonaniu.
