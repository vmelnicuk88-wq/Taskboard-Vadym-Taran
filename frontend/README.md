# Frontend TaskBoard

Strony `login.html`, `boards.html` i `board.html` korzystają z
Bootstrap 5 i stylów `css/style.css`. JavaScript wydzielono do
`js/login.js`, `js/boards.js` i `js/board.js`, a `js/api.js`
dostarcza wspólne zapytania HTTP.

Uruchom Express w folderze `backend` i otwórz
`http://localhost:3000/login.html`. Strony potrzebują API i sesji.
